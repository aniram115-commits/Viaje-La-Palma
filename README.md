# Viaje a La Palma

Mini app en Next.js para compartir el itinerario del viaje.

## Cómo usarla en local

```bash
npm install
npm run dev
```

Luego abre `http://localhost:3000`.

## Cómo editar el itinerario

Toda la información está en:

- `data/itinerary.ts`

Ahí puedes cambiar:
- títulos de los días
- horarios
- descripciones
- enlaces de mapas
- enlaces de fotos

## Cómo subirlo a GitHub

1. Descomprime este zip.
2. Crea un repositorio nuevo en GitHub.
3. Sube todos los archivos.

## Cómo publicarlo en Vercel

1. Entra en Vercel.
2. Importa el repositorio de GitHub.
3. Pulsa deploy.
4. Te dará una URL pública tipo `tu-app.vercel.app`.

La URL la puede abrir cualquiera con el enlace.
